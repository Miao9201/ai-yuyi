# 语忆AI

Windows 本地运行的微信与 QQ AI 聊天工具。通过微信 AI 会话聊天，无需保持电脑微信在前台。默认人设为虚构角色 **林慕婉**。

> 公开仓库只包含程序、默认虚构人设与明确标注的虚构样例。每个人的聊天、记忆、导入资料、媒体、密钥和微信授权均由使用者自行保存在本机。

> v1.1.0 为独立桌面窗口版，双击 EXE 即可打开完整管理界面。升级前请停止回复并关闭程序；旧版本的配置、人设和记忆会保留。

> QQ 为当前开发分支新增功能，既有 v1.1.0 安装包仍是微信版。接入步骤见 [QQ接入](docs/QQ接入.md)。

## 下载安装

在本仓库 **Releases** 下载 `YuYiAI-Setup.exe`，运行后打开桌面上的 **语忆AI**。安装版自带 Python 和 Node，无需自己安装运行环境；另有 `YuYiAI-portable.zip`，整包解压后打开其中的 `语忆AI.exe`。

第一次使用按以下顺序操作：

1. 打开软件，直接打开独立管理窗口。
2. 在 **API配置** 填入兼容 Chat Completions 的 HTTPS 地址、模型名称和自己的 API Key，检测后保存。
3. 点绿色 **开始回复**，出现二维码后，用你希望聊天的微信扫码并确认授权。
4. 在微信新出现的 **AI 会话** 中先发一句话，确认收到回复。
5. 需要识图时，配置支持图片输入的识图模型，并在 **参数** 中开启识图，再发普通图片测试。

完整说明见 [安装与微信 AI 接入](docs/安装与微信AI接入.md)。软件需要电脑保持开机联网，API 费用由使用者自行承担。

## 功能

| 功能 | 说明 |
|---|---|
| QQ 私聊与指定群 | 后台收发、图片理解、内置表情回发；群内 @、触发词及按概率接话，其他群默认不回复 |
| 微信 AI 会话 | 后台接收与回复；无需桌面微信保持前台，不需要额外微信小号 |
| 人设 | 修改、新建、切换人设；默认体验林慕婉 |
| 聊天记录导入 | 读取 JSON，选择两位说话人，建立本地独立人设资料库 |
| 表达风格与回忆 | 提取问答范例、近期表达统计、按日期保存历史片段，并在回复时检索相关资料 |
| 记忆编辑 | 按用户和人设搜索、新增、纠正、固定、删除、恢复与撤销软件内产生的记忆 |
| 图片理解 | 使用支持图片输入的模型识别收到的普通图片 |
| 图片与表情包回发 | 回发内置表情；导入媒体须明确启用，并保留原媒体文件 |
| 多用户 | 每位朋友各自扫码，独立授权、队列和新对话记忆；朋友默认体验林慕婉 |
| API 手动配置 | 自定义兼容地址、聊天/识图模型、温度、超时；本机 DPAPI 加密保存密钥 |
| 启停与状态 | 一个按钮切换绿色开始、红色停止；刷新真实状态和本机日志 |

导入功能使用检索和提示词参考，不会训练或修改模型权重，也不保证完整复制一个人的性格或记住所有往事。

总览按微信、QQ分别显示连接、账号、人设和回复范围。**人设**页上方可分别保存两个平台的默认人设，下方统一管理、编辑人设；单独保存编辑内容不会切换默认。QQ默认大肥鱼，微信默认林慕婉；QQ群聊跟随QQ默认，也可勾选“群聊单独指定”，群聊仅允许公开人设。用户页、参数页同样按平台分区，API统一配置。能力与验证边界见[微信与QQ功能核查](docs/功能核查.md)。

## 从 Alpha 导出后导入

可使用第三方工具 [Alpha](https://github.com/xunchahaha/alpha-releases) 将自己的微信会话导出成可读取的 **JSON**。导出时选择普通 `json`，保留说话人标识；需要图片与表情包时同时导出媒体，并保留 JSON 与 `media/` 的相对目录。

这里的 JSON 是普通导出文件，不是微信官方加密备份。语忆AI不能直接读取微信官方加密备份、数据库、HTML、Excel 或其他工具的任意 JSON 格式。具体字段与操作见 [导入、风格与媒体](docs/导入风格与媒体.md)。Alpha 的版本、兼容性与功能开放以其官方说明为准，本项目不附带 Alpha，也不要求打开其 HTTP API。

## 隐私

- `private/`：自己导入的人设、历史索引、表达范例与媒体目录信息。
- QQ接入端安装目录、QQ客户端资料目录也包含登录资料和缓存，不要上传。
- `data/`、`upstream-v1.2.0/data/`：本机配置、密钥、授权、新对话记忆、队列和日志。
- 这些目录在 Git 中默认忽略。不要上传正在运行的目录、备份或导出文件；公开源码使用全新默认模板。
- 模型回复和识图需要访问你配置的 API；相关对话、检索片段或图片会发送到该模型服务。请根据自己和聊天参与者的授权决定导入及使用范围。
- 管理页只监听本机回环地址，没有公网登录系统，请勿用端口转发公开管理页。

## 源码运行与构建

源码运行需要 **Windows x64、Python 3.12 x64、Node.js 24 或更高版本**：

```powershell
python -m pip install -r requirements.txt
powershell -NoProfile -ExecutionPolicy Bypass -File build-launcher.ps1
.\START.cmd
```

首次默认不启动自动回复，需要自行配置 API 和微信授权。源码目录中的默认数据模板均为空白，不含可用密钥或授权。

开发、测试、更新审核清单及构建说明见 [开发与构建](docs/开发与构建.md)。

## 常见问题

- **需要把微信放在前台吗？** 不需要。这里使用 iLink AI 会话；电脑需要开机、联网并运行回复服务。
- **能回复普通好友或群聊吗？** 微信对接 AI 会话；QQ新增普通私聊与指定群，需独立安装 NapCat 并设置允许对象。
- **可以去掉微信里的 AI 标识吗？** 标识由微信平台显示，控制台没有移除它的功能。
- **扫码没有 AI 会话或提示受限？** 以手机微信的提示为准。账号与平台功能开放情况可能不同，不能保证所有账号均可接入。
- **停止与关闭窗口一样吗？** 不一样。停止回复会停收发；关闭窗口只关闭管理界面，后台回复状态保持不变。
- **回复对象为什么是一串标识？** 授权接口没有返回昵称时，显示当前实际绑定的账号标识，不拿备注冒充自动获取的昵称。
- **识图失败？** 确认识图已启用、模型支持图片输入、API 余额及网络正常。识图和纯文本模型能力不同。
- **导入记录没有出现在记忆页？** 导入资料只用于人设检索；记忆页只管理软件内的新对话和手动补充。
- **朋友能访问我的导入人设吗？** 默认只能使用公开体验人设，不能访问主账号的私人资料库。

## 项目结构

```text
launcher.py                 本机控制台启动
account_store.py             微信账号与加密授权边界
qq_settings.py / qq_runtime.py  QQ配置、登录与本机接口
qq_context.py / qq_bot.py       QQ隔离记忆与工作进程
import_persona.py            通用 JSON 导入
companion_memory.py          检索、表达范例与媒体候选
memory_editor.py             按用户/人设管理新对话记忆
upstream-v1.2.0/console/      管理页面
upstream-v1.2.0/src/          对话、iLink、识图与媒体运行时
upstream-v1.2.0/personas/     公开人设
templates/                   全新默认配置
packaging/                   Windows 构建与安装器
```
