# 数据库与数据隔离

公开版保留完整的数据库建表、索引、迁移、检索和记忆编辑代码，不附带任何使用过的数据库。无需外部数据库服务器；首次使用对应人设记忆或导入功能时自动创建本机 SQLite 数据库。

## 保留的结构与功能

| 结构 | 用途 |
| --- | --- |
| `memories` | 导入片段、已确认对话及手动记忆，带来源和编辑状态 |
| `pairs` | 从导入记录提取的接话范例 |
| `memory_fts`、`pair_fts` | SQLite FTS5全文检索索引 |
| `meta` | 索引与数据库版本信息 |
| `memory_editor_audit` | 编辑、删除恢复和撤销所需的操作记录 |

初始化位于 `companion_memory.py` 的 `Knowledge`，编辑表迁移位于 `memory_editing.py`。角色导入、说话人选择、风格范例和媒体索引使用 `import_persona.py`；接口和管理界面使用同一套实现。

## 数据保存在本机

- 导入的真实记录、角色资料及媒体索引位于 `private/<人设>/`。原始导出文件不随软件升级修改。
- 软件产生的新对话按平台、用户/群和人设分开保存；QQ数据库位于 `data/qq/memories/`，微信与导入人设的路径由对应作用域决定。
- QQ群只允许公开角色，不检索私人人设及其他会话记忆。微信朋友账号保持独立授权与访问范围。
- 队列、收发确认和本机日志也属于运行数据，不属于公开模板。

发布的源码、安装包、便携包都只提供全新默认配置、林慕婉、大肥鱼和内置表情素材。运行后创建的数据库、聊天记录、API Key和授权文件不要提交GitHub或附在公开Issue中。升级安装保留现有本机数据；需要备份时由自己保存在私有位置。

验证数据库功能时，可使用[导入说明](导入风格与媒体.md)中的虚构JSON示例。开发回归使用临时目录和虚构记录，测试导入、检索、修改、恢复及隔离，不需要私人聊天记录。
