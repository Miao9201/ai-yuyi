# 微信与QQ功能核查

本轮沿用语忆AI桌面面板；用户明确选择不另部署AstrBot。参考来源：[项目说明](https://github.com/mtshang/make-your-qq-ai-group-member)、[参数模板](https://github.com/mtshang/make-your-qq-ai-group-member/blob/main/templates/astrbot_plugin_group_chat_plus_config.json)。

| 项目 | 微信 iLink AI会话 | QQ / NapCat |
| --- | --- | --- |
| 无需@的概率群接话 | 当前通道不支持群收发 | 基础概率10%，可改概率、间隔、每分钟上限、活跃/安静时段、触发词及生效群 |
| 群聊氛围判断 | 不适用 | 本地规则综合质量、注意力、情绪和疲劳；@别人/引用别人时默认不抢话 |
| 识图与人设 | 支持；微信默认独立选择，保留自定义 | 支持；默认“大肥鱼”，群聊跟随默认或单独指定，群仅允许公开角色 |
| 私聊和群@ | AI会话私聊支持；群@不支持 | 白名单私聊、指定群@及引用机器人回复 |
| 启停与状态 | 微信板块独立开关，顶部统一启停 | QQ板块独立开关、登录与真实进程状态，顶部统一启停 |

参数页分微信参数、QQ参数。模型地址、聊天/识图模型、密钥、温度和超时仍统一在API配置；共享模型高级参数也移到API页，避免误称只影响微信。微信新对话、QQ私聊、QQ群及不同人设的记忆继续隔离。

总览分别显示微信、QQ的连接状态、账号、人设与回复范围；长账号标识放在折叠详情。人设页上方独立设置微信和QQ默认，下方共享人设库，支持公开/私密筛选。保存编辑内容不会切换默认，应用默认也不会丢弃未保存的编辑草稿。用户页保存名单不会覆盖人设选择；旧版单独群聊角色会保留。

QQ群决策采用可测试的本地规则，并非原AGPL插件的完整移植：没有宣称新增其全部AI决策推理、欢迎消息、合并转发解析或工具系统。基础10%会被上下文系数调整，不保证每10条恰好回复1条。

验证覆盖：独立平台写入、参数作用域、加载失败不覆盖、群白名单/概率/时段/@/冷却/质量/情绪/疲劳、不同人设与记忆隔离、真实handler最终模型请求、大肥鱼角色和识图凭据保留。真实QQ文字、识图、群@及表情包曾由用户手机确认；本轮新概率策略使用注入随机数与时钟的行为测试，不能把这些测试称作手机全场景实测。

当前微信接入的群能力缺口需要另选具备微信群事件与发送能力的接入端，不能单靠增加面板开关实现。现有微信AI会话和登录资料不因此变更。
