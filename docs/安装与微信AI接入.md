# 安装与微信 AI 接入

## 1. 安装

适用于 Windows 10/11 64 位。需要联网和可用的默认浏览器；安装包包含 Python、Node 和程序依赖。

1. 进入本仓库 Releases，下载 `YuYiAI-Setup.exe`，同时可下载 `SHA256SUMS.txt` 校验文件。
2. 双击安装程序；完成后使用桌面“语忆AI”快捷方式。无需管理员权限，默认安装到当前 Windows 用户的程序目录。
3. 便携版须将 `YuYiAI-portable.zip` **全部解压** 到可写目录，再运行其中 `语忆AI.exe`。不要从压缩包内直接启动，也不要单独复制 EXE。
4. 软件会启动本机服务并打开浏览器。通常地址为 `http://127.0.0.1:7788`；端口被占用时自动尝试 7789—7797。实际地址保存在本机 `data/console.json`。

安装器不要求关闭安全软件，也不会添加防护排除。如果系统提示拒绝访问、文件消失或拦截，请记录提示及安装目录的 `install-error.log`，先核对来源和校验值。不要把包含账号或聊天的完整日志直接发到公开 Issue。

## 2. API 配置

进入 **API配置**，填写：

| 字段 | 填写内容 |
|---|---|
| 接口地址 | 平台提供的兼容 Chat Completions 的 HTTPS 基址；按平台文档决定是否包含 `/v1` |
| 聊天模型 | 账号实际可调用的模型 ID；可手动填，或读取模型列表 |
| 识图模型 | 支持图片输入的模型 ID；纯文本模型不能靠改名字获得识图能力 |
| 温度 | 控制回复变化程度，可先使用默认值 |
| 超时 | 网络或模型较慢时适当调高 |
| API Key | 仅填在本机页面，不发给微信机器人或公开仓库 |

“检测接口”不会保存；点击“保存”才应用。密钥留空会保留已有密钥，页面不会重新显示明文密钥。密钥使用 Windows 当前用户 DPAPI 保护；复制密钥文件给其他电脑通常不能直接使用。

若希望识图，除选择模型外，还需在 **参数** 中找到“识图”开关并开启。识图使用同一兼容接口地址与已配置的密钥（默认提供商路径）；如改用备用提供商，需要按参数说明另行配置。先发普通照片验证；表情包、语音、视频的支持情况不等同于普通图片。

## 3. 连接主账号

1. 确认 API 已保存，点顶部绿色 **开始回复**。
2. 等待控制台显示微信二维码，用平时要与机器人聊天的微信扫描。
3. 在手机微信确认连接。二维码过期时管理页会更新。
4. 在手机微信中找到新出现的 AI 会话，发送“你好”，等候回发。
5. 顶部红色 **停止回复** 表示当前可以点击停止；绿色 **开始回复** 表示当前已停止，可以点击开始。旁边状态文字与“刷新状态”用于核对真实连接状态。

这是 iLink AI 会话，不是普通微信小号托管。无需额外小号，也不用让电脑微信聊天窗口保持前台。电脑应保持开机联网，回复工作进程持续运行。微信平台可能限制账号、会话或能力；扫码提示及 AI 标识由微信控制。

## 4. 邀请朋友

1. 管理页打开 **用户**，填写朋友备注，新增用户。
2. 打开这位用户的二维码，让朋友用自己的微信扫码确认。
3. 朋友在自己的 AI 会话发送第一条消息。
4. 每人独立保存授权、队列与记忆；默认只体验林慕婉。不要用已绑定账号重复绑定其他用户。

“暂停／恢复”只控制对应朋友；顶部“开始／停止回复”控制整个服务。删除朋友会撤销授权和列表项，历史文件仍暂存本机；如需彻底清理，应先备份并确认删除范围。

所有使用者共用管理者配置的模型 API，费用由管理者的平台账号承担。管理页面仅供运行电脑的管理员使用，不提供给朋友公网访问。

## 5. 人设与记忆

在 **人设** 修改内容，点击“保存并设为默认”用于主账号后续回复。导入自己的 JSON 请参阅 [导入、风格与媒体](导入风格与媒体.md)。

**记忆** 可选择用户与人设，编辑本软件产生的新对话和人工补充；支持固定、搜索、删除恢复和撤销。外部导入的历史片段与表达范例保存在独立人设资料库，不在记忆管理中展示。

## 6. 升级与排错

- 升级前点击“停止回复”并关闭使用中的程序文件，再运行新安装器。已有数据、授权、私人角色及编辑过的人设不会被默认配置覆盖，仍建议先自行备份。
- 页面打不开：重新用桌面快捷方式启动；检查实际地址和本机端口，查看本机 `data/console.log`。不要把回环地址改成公网地址。
- 有连接但不回复：检查全局及对应用户是否暂停、API 余额/模型/超时、微信授权是否过期，再看日志中对应状态。
- 收到消息后等待时长取决于模型与网络；没有固定回复秒数。连续模型错误会重试，发送结果不明确时不会盲目重复发送。
- 授权失效：停止后再开始，按手机提示重新扫码；朋友可在用户页重新授权。
- 防护软件拦截：保留提示、校验值和失败日志，向项目提交脱敏后的信息；不要通过关闭防护来掩盖安装失败。
