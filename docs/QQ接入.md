# QQ 接入

QQ 与微信共用语忆AI的桌面面板、API配置、人设、识图和媒体功能。QQ需要独立的 NapCat OneKey 运行环境；不需要安装 AstrBot。当前QQ功能位于开发分支，已发布的 v1.1.0 安装包仍为微信版。

## 安装与登录

1. 使用 Windows x64。按 [NapCat 官方 Windows 一键安装说明](https://napneko.github.io/guide/boot/Shell) 下载、完整解压 `NapCat.Shell.Windows.OneKey.zip`，运行 `NapCatInstaller.exe`。本次验证使用 NapCat v4.18.41 与独立 QQ 9.9.33-52230。
2. 安装完成后找到 `NapCat.XXXX.Shell` 目录。这个目录应同时包含 `QQ.exe`、`NapCatWinBootMain.exe` 和 `versions`。请保留整个目录，不要只复制启动器，也不要填写普通QQ安装目录。
3. 打开语忆AI的 **用户 → QQ → QQ运行环境**，填写该目录并点击 **保存目录**。语忆AI将配置专用的本机管理端和连接令牌；请使用独立目录，不要指向已经承担其他机器人任务的 NapCat。
4. 在 **API配置** 保存自己的兼容接口和模型。微信已配置过时直接共用；识图仍需支持图片输入的模型，并在 **参数 → QQ参数** 开启识图。
5. 在QQ区块填写允许私聊的QQ号、允许回复的群号和私聊人设，勾选 **启用QQ**，点击 **保存QQ设置**。群号留空表示所有群均不回复。
6. 让机器人小号退出电脑普通QQ，手机小号保持在线。点击 **扫码登录 / 刷新二维码**，用手机小号扫码并确认，等待状态显示实际小号昵称及QQ号。不要同时在普通电脑QQ登录同一个小号。
7. 点击顶部 **开始回复**。状态显示后台监听后，用允许的大号给小号发送文字、图片，再在允许的群中 @小号测试。QQ窗口无需前台；电脑仍需开机联网。

语忆AI会在这个专用运行目录配置正向 WebSocket；默认管理端为 `127.0.0.1:6099`，消息端为 `127.0.0.1:3001`。令牌在本机加密保存，普通配置接口不返回明文。不要开放公网端口或分享管理端令牌。QQ客户端自身也可能在用户文档目录保存登录资料，这些资料不属于可发布源码。

## 日常调整

- **用户 → QQ**：平台开关、私聊对象、指定群和私聊人设。修改列表后保存；其他私聊及其他群不回复。
- **参数 → QQ参数**：普通消息的参与概率、冷却时间、每分钟上限、触发词、活跃时段与安静时段。@机器人、引用机器人回复和触发词可优先接话，仍受群白名单、冷却和频率上限限制；@全体成员不会单独触发。
- **记忆**：选择QQ私聊或群对应的作用域。微信、QQ、不同私聊、不同群及不同人设的新对话分别保存。导入的原始资料继续在人设资料库中，只读检索，不移入新对话列表。
- QQ私聊和群聊默认大肥鱼，可在各自选择器切换；群聊只允许公开角色，不检索私人导入资料。私聊使用管理员在本机选择的人设，可沿用该人设的导入风格、回忆及已许可媒体。
- 顶部 **停止回复** 同时停止已启用平台的回复；不会退出手机QQ，也不清除扫码授权。关闭管理窗口会保留后台状态。微信和QQ在各自板块独立保存开关；都启用时由顶部同一个按钮控制。

## 排错

- 手机说登录成功，面板还在等扫码：先刷新状态。若日志提示“当前账号已登录，无法重复登录”，请完全退出电脑普通QQ中的机器人小号，再连接机器人运行端；不要反复登录普通QQ。
- 二维码过期：点击刷新二维码，用当前显示的码扫码。以面板取得实际账号和监听状态为准。
- 登录成功但不回复：检查顶部启停、QQ平台开关、私聊/群白名单、API、群冷却和频率上限。群聊只有部分普通消息会按概率回复。
- QQ断线：后台独立重连，微信工作进程不受影响。发送结果不明确时不会自动重复发送；需要时查看本机日志和记忆。
- 图片：支持已验证的QQ图片地址或本机专用缓存，限制类型与大小；无法读取时不编造图像内容。图片、动图识别与文字回复已实际验证；语音、视频及文件理解未在本次新增范围内。

NapCat为非官方QQ接入方式，可能遇到登录限制或平台风控，不能保证账号长期可用。其自身适用 [NapCat v4.18.41 许可证](https://github.com/NapNeko/NapCatQQ/blob/v4.18.41/LICENSE)，不由本项目MIT许可替代；语忆AI不打包分发NapCat或QQ客户端。

## 与参考项目的对齐范围

基础群接话概率默认10%，实际值会随消息质量、近期注意力、规则识别的情绪和近期回复疲劳调整；普通接话受活跃时段约束，安静时段降低概率。@与点名仍受白名单、冷却和每分钟上限约束，引用其他群友或@其他人时默认不抢话。此处是本项目的本地规则实现，不等于原插件全部AI决策、工具、合并转发、欢迎消息等扩展。

微信当前使用iLink AI会话，支持私聊、图片、人设、记忆与启停，不支持微信群收发或群@。这些能力未伪装为可设置项目。日常使用语忆AI桌面面板，不部署重复的AstrBot服务。
